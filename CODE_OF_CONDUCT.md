# Community standards

Participation in this project is expected to be respectful and constructive.

- Be considerate in discussions and reviews.
- Critique ideas and changes, not people.
- Share only information you have the right to disclose.
- Follow the project license and Windows safety guidance.

Harassment, threats, discriminatory behavior, and deliberate disruption are not acceptable. Project maintainers may edit or remove contributions that violate these standards.

Report conduct concerns privately to the repository owner or maintainer.
