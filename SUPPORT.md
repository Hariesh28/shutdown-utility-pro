# Support

This is a personal Windows utility project. For help:

1. Read `README.md` and `docs/SETUP.md`.
2. Check the application log at `%LOCALAPPDATA%\ShutdownUtilityPro\Shutdown.log`.
3. Report reproducible bugs using the GitHub bug report template, including Windows version, reproduction steps, and relevant log excerpts.

Do not include credentials, personal files, or unrelated system logs in an issue. For security issues, follow `SECURITY.md` instead of filing a public issue.

Support is provided on a best-effort basis; no response-time guarantee is made.
